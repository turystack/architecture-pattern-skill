# @turystack/architecture-pattern

Architecture constitution skill — the law that survives a change of stack: topology, layers, contracts, consistency, delivery boundaries, cross-stack seams, idempotency, resilience and observability. Installed into .claude/skills and/or .codex/skills via the turystack CLI.

## Installation

```bash
pnpm add -D @turystack/architecture-pattern
```
